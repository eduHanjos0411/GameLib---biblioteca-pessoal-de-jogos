# Game Library Manager

Sistema web para gerenciamento de uma biblioteca pessoal de jogos.

## Funcionalidades

- Gerenciamento de jogos da biblioteca
- Organização por status:
  - Para jogar
  - Jogando
  - Finalizados
- Filtros por status
- Acompanhamento do progresso dos jogos
- Cadastro e gerenciamento de informações dos jogos
- Organização da biblioteca em uma interface simples e intuitiva

## Objetivo

O projeto tem como objetivo facilitar a organização e o acompanhamento de uma biblioteca pessoal de jogos, permitindo visualizar o que já foi finalizado, o que está em andamento e quais jogos ainda estão pendentes.
